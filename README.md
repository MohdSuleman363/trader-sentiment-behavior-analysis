# Trader Sentiment & Behavior Analysis

This project analyzes how market sentiment (Fear & Greed Index) affects trader behavior and profitability.

---

## Requirements

Python 3.9+

Install dependencies:

pip install pandas numpy matplotlib seaborn scikit-learn streamlit

---

## How to Run

### Option 1 — View analysis

Open the notebook:

Trader_Sentiment_Analysis.ipynb

All outputs are pre-executed.

---

### Option 2 — Run interactively

Run all cells from top to bottom.

---

### Optional — Launch dashboard

streamlit run app.py

---

## Files

* `Trader_Sentiment_Analysis.ipynb` → Main analysis
* `SUMMARY.md` → 1-page project findings
